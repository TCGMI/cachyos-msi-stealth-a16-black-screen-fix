# Contributing

Reports from similar AMD/NVIDIA hybrid laptops are welcome.

Please include the exact laptop model, GPU models, kernel version,
NVIDIA driver version, desktop environment, display manager, and whether
the session uses Xorg or Wayland.

Do not post passwords, serial numbers, account information, public IP
addresses, or unrelated logs containing personal information.

If proposing a change to the documented fix, explain the hardware and
software configuration on which it was tested. Avoid presenting a
hardware-specific workaround as universal.
